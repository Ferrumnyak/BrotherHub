# BrotherWatch для разработчиков

## Как это работает

- У каждого участника видео открывается у себя: по ссылке (через yt-dlp) или
  из локального файла. По сети передаются только команды и позиция, поэтому
  требования к интернету минимальные.
- Ведущий — источник времени: его пауза, запуск и перемотка уходят на сервер,
  плюс раз в 2 секунды он сообщает позицию. Остальные подстраиваются: при
  небольшом расхождении — скоростью ±5 %, при большом — перемоткой.
- Сервер хранит комнаты в памяти, пересылает чат и состояние воспроизведения.
  При обрыве связи 30 секунд держит место за участником.
- Голос идёт через LiveKit; пропуск в голосовой канал (JWT на 5 минут, только
  микрофон) выдаёт наш сервер после проверки пароля.

## Структура

| Папка            | Что внутри                                                        |
|------------------|-------------------------------------------------------------------|
| `shared/`        | Протокол: типы сообщений клиент ⇄ сервер                          |
| `server/`        | Сервер (axum + WebSocket): комнаты, чат, синхронизация, пропуска в голос |
| `app/`           | Приложение на Tauri 2, интерфейс на React + TypeScript            |
| `app/src-tauri/` | Rust-часть приложения: связь с сервером, mpv, встраивание видео, синхронизация, «нажми и говори» |
| `deploy/`        | Запуск на сервере: Docker Compose, LiveKit, Caddy                 |
| `scripts/`       | Сборка: скачивание mpv и yt-dlp, сборка релиза                    |
| `docs/`          | Инструкции                                                        |

## Стек

- Rust; интерфейс — React + TypeScript, шрифты Manrope и Unbounded
- Tauri 2 (Windows)
- mpv + yt-dlp, управление через JSON IPC; видео встроено в окно (`--wid`)
- LiveKit (WebRTC) для голоса
