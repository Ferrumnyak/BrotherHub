# BrotherWatch

Десктопное приложение для совместного просмотра фильмов, сериалов и шоу с друзьями:
синхронное воспроизведение, голосовая связь и текстовый чат.

## Как это работает

- У каждого участника свой файл (или ссылка на YouTube / VK Видео / Rutube).
  Приложение синхронизирует паузу, перемотку и позицию между всеми в комнате.
- В каждой комнате есть глава лобби 👑 — первый вошедший. Только он выбирает, что
  смотрим, и управляет паузой и перемоткой. Глава может передать роль другому
  или исключить участника; если глава вышел, роль переходит к следующему.
- Сервер хранит комнаты, пересылает сообщения чата и состояние воспроизведения.
- Видео по сети не передаётся, поэтому требования к интернету минимальные.

## Структура

| Папка            | Что внутри                                                 |
|------------------|------------------------------------------------------------|
| `shared/`        | Протокол: типы сообщений клиент ⇄ сервер (Rust)            |
| `server/`        | Сервер на Rust (axum + WebSocket): комнаты, чат, синхронизация |
| `app/`           | Приложение на Tauri 2: интерфейс на React + TypeScript      |
| `app/src-tauri/` | Rust-часть приложения: связь с сервером, управление mpv, встраивание видео, синхронизация |
| `deploy/`        | Docker-файлы для запуска сервера                           |
| `docs/`          | Инструкции                                                 |

## Стек

- **Язык:** Rust, интерфейс — React + TypeScript
- **Оболочка приложения:** Tauri 2 (Windows)
- **Плеер:** mpv + yt-dlp (управление через JSON IPC)
- **Голос:** LiveKit (WebRTC); пропуска в голосовой канал выдаёт наш сервер

## Запуск

- Подготовка Windows и запуск в режиме разработки: [docs/SETUP-WINDOWS.md](docs/SETUP-WINDOWS.md)
- Сервер в Docker (из корня репозитория):

  ```bash
  docker compose -f deploy/docker-compose.yml up -d --build
  ```
